## Project Overview

The Smart Display is a Raspberry Pi-based touchscreen display that shows weather information, indoor sensor data, photos, and Spotify playback controls. It features:

- Weather display with current conditions and forecast
- Indoor temperature, humidity, pressure, and air quality monitoring
- Photo slideshow functionality
- Spotify integration with playback controls
- WiFi setup and configuration
- Settings management
